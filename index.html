✓=이름 검증됨 · ⚠=추정 이름(빈 응답이면 실제 이름 확인). 인챈트는 API 규칙상 "인챈트 스크롤 (무기한)" 통합 조회 후 종류별로 걸러서 보여줍니다. 스캔 결과는 저장되지 않는 미리보기예요 — ★해야 기록이 쌓입니다.

📋 넥슨마켓 목록 붙여넣기

아바타·포장 아이템(포장된 ○○)은 넥슨마켓에서만 거래돼서 게임 API에 없어요. market.nexon.com의 목록 페이지를 전체 선택 → 복사해서 여기 붙여넣으면 이름·최저가·매물수를 자동으로 뽑아 기록합니다.

🔎 아이템명 검증기

API는 400=그런 이름 없음, 200+빈배열=이름은 맞지만 최근 24시간 거래 10건 미만으로 답해요. 이 차이로 진짜 이름을 가려냅니다. 한 줄에 하나씩 후보를 넣고 돌리세요.

🏪 넥슨마켓 목록 붙여넣기

포장된 ○○(아바타·룬 포장본)은 자동 수집이 불가능해요. 게임 API엔 아이템 자체가 없고(400), 넥슨마켓 백엔드는 목록 조회에도 로그인을 요구합니다(실측 확인). 대신 market.nexon.com 목록 화면을 전체 선택→복사해서 붙여넣으면 이름·가격·매물수를 한꺼번에 읽어 기록해요. 한 달에 한두 번이면 충분합니다.
