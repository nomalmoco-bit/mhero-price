이벤트 달력

넥슨 이벤트 공지는 자동수집이 data/events.json에 모아주고, 열 때 자동으로 달력에 들어와요(자동 표시). 지우면 다시 안 올라옵니다.

이벤트 전후 성과 —

이벤트 7일 전→당일→7일 후 변화율(±3일 내 기록 사용). 차익 패턴 ①②를 데이터로 배우는 곳.

감각 노트 — 차익의 4가지 패턴

① 이벤트 선행 매집 — 공지 직후 매수, 수요 폭발 때 매도.
② 신캐 사이클 — 신캐 발표 → 무기·인챈트 매집 → 출시 직후 매도.
③ 아바타 순환 — 출시 폭등 → 2~3개월 급락 → 재출시 추가 하락.
④ 굴비 시세 활용 — 골드 쌀 때 캐시템→골드, 비쌀 때 반대로.
지표 — RSI 70↑과열·30↓과매도 / 골든크로스=상승 전환 / 볼린저 상단=단기 과열 / MDD=최대 낙폭 / ₩모드=인플레 보정 실질가치.
지표는 참고지 정답이 아님(표본 적을수록). 사설거래 = 계정 제재, 금지.

종목 탐색 — 거래소 카탈로그

✓=이름 검증됨 · ⚠=추정 이름(빈 응답이면 실제 거래소 이름으로 수정 필요). 인챈트는 API 규칙상 "인챈트 스크롤 (무기한)" 통합 조회 후 종류별로 걸러서 보여줍니다. 스캔 결과는 저장되지 않는 미리보기예요 — ★해야 기록이 쌓입니다.

직접 추가

☁ Gist 동기화 — 폰↔PC 공유

읽기는 설정이 필요 없어요 — 열면 자동으로 최신 기록을 받아옵니다. 토큰은 기록을 올릴 기기에서만 넣으면 돼요.
Gist ID는 내 것이 기본으로 들어가 있어요 — 다른 기기에선 토큰만 넣으면 이어집니다. 토큰은 이 기기에만 저장되고 파일·백업·Gist 어디에도 안 들어가요.
⚠ GitHub의 'secret' gist는 비공개가 아닙니다(ID를 아는 사람은 읽을 수 있음). 그래서 업로드할 때 API 키는 자동으로 빼고 시세·모의거래 기록만 올려요. 공개되면 곤란한 내용은 넣지 마세요.

잠금 — 본인 확인

공개 페이지라 이 잠금은 암호화가 아니라 간단한 본인 확인이에요(개발자도구로 데이터를 볼 수 있음). 진짜 자물쇠는 님만 가진 Gist 토큰입니다.

API·자동화 설정

⚠ 넥슨 API는 자사 도메인에서만 브라우저 호출을 허용해요(CORS). 그래서 이 페이지에서 직접 조회는 차단되고, 시세는 GitHub Actions 자동수집을 통해서만 들어옵니다. 키는 저장소 Secret에 넣으세요 — 여기 키 칸은 다른 환경에서 쓸 때를 위한 예비입니다.
